# 指標の定義（v1.2）

日本語 | [English](metrics.en.md)

jacer の正規化の詳細を説明します。

## 1. 文字と記号（3指標共通）

- 全角・半角の違い、連続する長音符（`ーー`）や波ダッシュは統一します。
- 英字の大文字・小文字の違いは統一します（`Apple` / `apple`、`iPhone` / `IPHONE`）。
- 空白、句読点、読み上げない記号（引用符、`♪`、`※`、`：` など）は取り除きます。`「」` と `『』` は引用符として扱い、中身は残します。
- 読み上げる記号は残します：`% & # @ / °`、数学記号（`+ = < > × ÷ ± ~` など）、通貨記号（`$ ¥ € £ ₩` など）。
- `.` と `:` は、数字に挟まれている場合だけ残します（`3.5` と `35` などを区別するため）。
- 括弧（`()` `[]` `{}` `<>` `【】` `〔〕` `〈〉` `《》` `〖〗` `〘〙` `⦅⦆` とその全角形）は、中身ごと削除します（`(笑)`、`[音楽]`、`<noise>`、ルビなど）。
  - 例外：中身がもう一方の文でも発話されている場合は、括弧だけを取り除いて中身は残します。
  - 例外：数字を含む `<...>` は不等号として残します（`3<5かつ6>4`）。
- ゼロ幅スペースなど、非表示文字を取り除きます。

## 2. 数字・時刻・単位（3指標共通）

次の表記の違いは、すべての指標で正解とみなします。

| 種類 | 例（正解文 / 認識結果） |
|---|---|
| 数字 | `百八十五` / `185`、`二〇二六` / `2026`、`三万五千` / `35000` / `3万5000` / `35,000`、`合計、１、０００名` / `合計千名`、`一人` / `1人` |
| 番号 | `090-1234-5678` / `09012345678`、`〇一〇一` / `0101` |
| 時刻 | `12時` / `12:00`、`9時5分` / `9:05`、`12時半` / `12:30` / `12時30分` |
| 金額 | `100ドル` / `$100`、`500円` / `¥500` |
| `&` | `AアンドB` / `A&B` |
| 単位 | `5メートル` / `5m`、`500グラム` / `500g`、`2リットル` / `2L`、`50ヘルツ` / `50Hz`、`30平方メートル` / `30㎡`、`30度` / `30℃`、`100%` / `100パーセント` |
| 単位の省略形 | `5キロ` / `5km`、`体重60キロ` / `体重60kg`、`10センチ` / `10cm`、`64ギガ` / `64GB`、`何キロ` / `何km` |
| 範囲 | `3から5人` / `3〜5人`、`10から15%` / `十から十五パーセント` |
| 分数 | `2分の1` / `1/2` |
| 日付 | `10月1日` / `10/1`、`2026年10月1日` / `2026/10/1` |
| 漢数字の小数 | `2.5倍` / `二点五倍` |

複数の意味に取れる表記は、正解文と一致する意味で解釈します（例：`キロ` は km とも kg とも、`10/1` は日付とも分数とも取れます）。

数字の間の読点は、後ろがちょうど3桁の数字なら桁区切り（`１、０００` は 1000）、それ以外は数の区切りとして扱います。`三、四週間`（3週間か4週間）は 34 という1つの数ではなく、3 と 4 として比較します（`三、四週間` / `3、4週間` は正解）。

0で始まる数字（`0110`、`〇一〇一`）は番号とみなし、1桁ずつ比較します（`0110` / `110` は誤り）。

例外として、以下は統一されません。

- 数字を伴わない `から` やスラッシュ（`東京から大阪` / `東京〜大阪`）
- 演算子（`1プラス1` / `1+1`）
- 比（`3対2` / `3:2`）
- 数字を伴わない英字の略語（`新曲のMV` の `MV` はメガボルトとみなしません）

## 3. 語の書き方（cer_strict と cer_flex で扱いが異なる）

同じ語の書き方の違いは、指標ごとに次のように扱います。

| 正解文 / 認識結果 | cer_strict | cer_flex |
|---|---|---|
| 漢字が同じで送り仮名だけが異なる（`申し込む` / `申込む`、`取り扱い` / `取扱い`、`断る` / `断わる`） | 正解 | 正解 |
| 助数詞（`3ヶ月` / `3か月` / `3カ月`、`3ヶ所` / `3か所`） | 正解 | 正解 |
| `々`（`時々` / `時時`） | 正解 | 正解 |
| 外来語のカタカナ表記の違い（`コンピューター` / `コンピュータ`、`バイオリン` / `ヴァイオリン`、`ウイルス` / `ウィルス`） | 正解 | 正解 |
| 漢字と仮名（`お願い` / `おねがい`、`会議` / `かいぎ`、`今日` / `きょう`、`私` / `わたし`） | 誤り | 正解 |
| 漢字の語と、その読みを仮名で書いたもの（`日本` / `にほん`、`日本` / `にっぽん`。読みが複数ある語はどの読みでも可） | 誤り | 正解 |
| 同じ語の異なる漢字（`聞く` / `聴く`、`分かる` / `解る`） | 誤り | 正解 |
| ひらがなとカタカナ（`りんご` / `リンゴ`） | 誤り | 正解 |
| 発音の異なる仮名同士（`にほん` / `にっぽん`、`わたし` / `わたくし`） | 誤り | 誤り |
| 同音異義語（`機関` / `期間`） | 誤り | 誤り |

外来語のカタカナ表記は、長音の有無（`コンピューター` / `コンピュータ`）、小さい母音（`ウィルス` / `ウイルス`）、`ヴ` と `バ` 行の書き分けだけが違う場合に正解とみなします。

仮名で書いた数字（`ひとり`、`ひとつ`）も漢字と仮名の違いとして扱うので、`ひとり` / `1人` や `ひとつ` / `一つ` は cer_flex でのみ正解です。

## cer_kana

cer_flex と同じ処理をした文を、OpenJTalk でカタカナの読みに変換して比較します。cer_flex が正解とみなすものに加え、同音異義語（`機関` / `期間`）も正解とみなします。

なお、読みは OpenJTalk による推定のため、OpenJTalk が読みを誤った場合（読みが複数ある語、固有名詞、辞書にない語など）は、その誤りもスコアに含まれます。ユーザー辞書（`load_user_dict`）で特定の語の読みを追加できます（`Siri` → シリ）。

## 対象外とするもの

| 正解とみなさないもの | 理由 |
|---|---|
| 言い換え・同義語・文体（`午後3時` / `15時`、`3割` / `30%`、`半分` / `2分の1`、和暦 / 西暦、`です` / `である`） | 発話された内容が異なるため |
| 英字表記とカタカナ表記（`Apple` / `アップル`） | 現在は未対応。cer_kana では、OpenJTalk が英字の読みを知っている語（`Apple`、`Google` など）に限って正解になります。知らない語（`Siri`、`ChatGPT` など）はアルファベット読みになるため誤りです |
| 旧字体・異体字（`髙` / `高`） | 固有名詞では意図的に使い分けていることが多いため |
